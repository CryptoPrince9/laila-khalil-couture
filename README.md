# LAILA KHALIL • Haute Couture 3D Interactive WebGL Atelier & Runway Platform

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FCryptoPrince9%2Flaila-khalil-couture)

An interactive 3D animated fashion designer website for designer **Laila Khalil**. Built with WebGL (Three.js), modern CSS design tokens, runway video catwalk showcases, procedural ambient audio synthesis, bespoke made-to-measure sizing, and dual global payment gateways (**Wise Multi-Currency Wire & MetaMask Web3 Crypto Escrow**).

---

## 🌟 Key Features

1. **3D Interactive Haute Couture Atelier:**
   - 360° orbiting camera with drag-to-rotate and scroll zoom.
   - Real-time cloth wave physics simulation (runway catwalk breeze & motion).
   - Fabric texture engine: *Noir Silk Satin, Champagne Gold Brocade, Emerald Royal Velvet, Rose Blush Organza, Liquid Silver Chrome*.
   - Studio lighting presets: *Runway Spotlight, Golden Hour Sunset, Midnight Noir, Studio High-Key*.
   - Mode switcher: Toggle between 3D Mannequin & Gown view and 3D Rotating Video Carousel.

2. **The 4 Runway Collection Videos (Catwalk Showcases):**
   - **Look 01: The Celestial Noir** — Asymmetrical draped evening gown.
   - **Look 02: Imperial Saffron Elegance** — Sculptural high-collar structured ensemble.
   - **Look 03: Aura of Alexandria** — Cascading silk chiffon kaftan gown.
   - **Look 04: The Modern Architect** — Bespoke contemporary tailored suit set.
   - Real-time video player with auto-play on hover, 0.5x slow-motion catwalk playback, individual audio toggle, and full-screen 4K theater modal with Bill of Materials and ISO 4915 stitch callouts.

3. **Dual Global Payment Infrastructure:**
   - **Wise Multi-Currency Direct Wire:** Direct transfers in USD, EUR, GBP, AED, SAR, and EGP with zero exchange markups, official IBAN, SWIFT/BIC, ACH routing, and automated payment reference code matching (`LK-XXXX`).
   - **MetaMask Web3 Crypto:** Non-custodial instant settlement in Ethereum (ETH), USDT, and USDC with automated Web3 connection, gas estimation, and direct Ethereum address / QR code fallback.

4. **Designer Laila Khalil Merchant & Setup Hub:**
   - Step-by-step onboarding guide for Laila Khalil to register and activate her Wise Business multi-currency accounts.
   - Step-by-step onboarding guide to create and secure her MetaMask Web3 wallet.
   - Live merchant settings manager to update her Wise tag and MetaMask address at any time (instantly updates live checkout without code changes).
   - Order management dashboard to track orders, measurements, and export orders to JSON.

5. **Procedural Web Audio Runway Synthesizer:**
   - Ethereal catwalk ambient chord pads and subtle sub-bass pulse generated via Web Audio API with zero external audio assets.
   - Audio visualizer equalizer bars in header.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/CryptoPrince9/laila-khalil-couture.git
cd laila-khalil-couture

# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Or run zero-dependency Node server
node server.js
```
Local server will be available at: `http://localhost:5173`
